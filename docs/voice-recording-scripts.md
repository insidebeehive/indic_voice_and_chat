# Voice recording scripts — IndicF5 fine-tune (male voice)

Two scripts built from the real voicebot campaign dialogue (greeting, talking
points, objection answers, closings) plus the support-bot phrasing the agent
uses on live calls — so the fine-tune hears exactly the vocabulary it will
speak: amounts, bonuses, withdrawals, OTPs, brand words, farewells.

**Script A** is Hindi written in English letters (read it aloud in Hindi, as
written). **Script B** is Marathi in Devanagari, with a small Roman reading
aid under each line. All lines use male grammatical forms to match the voice.

### Recording tips

- Quiet room, same mic distance throughout; one line per take, ~1s of silence
  before and after each line.
- Conversational phone-call energy — warm and natural, not "announcer" voice.
  Questions should genuinely rise like questions.
- Read numbers exactly as written in words (they're spelled out on purpose).
- If you fumble, just pause and re-read the line — trim later.
